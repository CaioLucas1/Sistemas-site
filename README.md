# Sistemas de site
O planejamento do site voltado para filmes e séries teve como objetivo principal criar uma plataforma informativa e interativa para o público. O site oferece conteúdo diversificado, como notícias (Blog), opções de compras (Galeria) e um canal de comunicação (Contato). Sua estrutura é organizada em páginas específicas: "Início", "Galeria", "Contato" e "Blog", facilitando o acesso às informações de interesse dos usuários.

![home2](https://github.com/user-attachments/assets/ca402acc-e9f8-4008-8cbb-08f88651f756)

O projeto também inclui funcionalidades importantes, como uma página inicial intuitiva, sistema de contato direto e recomendações personalizadas com base nas preferências dos visitantes. O design é responsivo, garantindo uma boa experiência de uso em diferentes dispositivos.

Durante o planejamento, foram consideradas etapas essenciais como a pesquisa do público-alvo, definição da identidade visual, escolha das tecnologias a serem utilizadas (front-end e back-end) e a elaboração de um cronograma de desenvolvimento.
